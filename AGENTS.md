# Proyecto Física II

Desarrollar cuatro aplicaciones web independientes
para las unidades del curso de Física II.

## Tecnologías
- React
- Vite
- JavaScript
- CSS
- SVG y Canvas
- Three.js solo cuando sea necesario

## Reglas
1. Cumplir los requisitos de cada unidad.
2. Mantener el código sencillo.
3. Evitar dependencias innecesarias.
4. Priorizar cálculos físicos correctos.
5. Utilizar unidades del Sistema Internacional.
6. Crear interfaces sencillas.
7. No implementar backend ni bases de datos.
8. No crear documentación extensa.
9. No modificar otras unidades.
10. Ejecutar pruebas básicas.

## Organización
Cada unidad debe tener su propia carpeta
y funcionar independientemente.

## Respuestas
Responder brevemente:
- Qué se implementó.
- Cómo ejecutar.
- Qué pruebas se realizaron.
- Qué limitaciones existen.
