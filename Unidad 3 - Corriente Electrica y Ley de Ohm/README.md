# Unidad 3: Corriente Eléctrica y Ley de Ohm

Aplicación independiente con Ley de Ohm, circuitos en serie, paralelo y mixtos, diagramas SVG y cálculos en unidades SI.

```bash
npm install
npm run dev
```

Pruebas: `npm test`. Compilación: `npm run build`.

Consulta [GUIA_DEL_PROYECTO.md](GUIA_DEL_PROYECTO.md) para instalación, uso, fórmulas, ejemplos y validación.
